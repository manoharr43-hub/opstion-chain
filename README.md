# 📊 NSE Option Chain Scanner

A Streamlit‑based dashboard to analyze **NSE Option Chain data** with live indicators, signals, and visualization.

---

## 🚀 Features
- Fetch NSE Option Chain data (Top 500 stocks).
- Calculate EMA20, EMA50, RSI, VWAP, ATR.
- Generate BUY / SELL signals with multi‑timeframe confirmation.
- Interactive dashboard with metrics and charts.
- Deployable on **Streamlit Cloud** or **Hugging Face Spaces**.
